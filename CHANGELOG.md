# Changelog

## 1.0.3 — 2026-10-08

- Refined the reader-facing documentation and repository layout.
- Preserved the explorer, static-site workflow, catalog, reference documents, and browser security controls.

## 1.0.2 — 2026-10-08

- Added an explicit publication file allowlist for project assets.
- Added a publication audit for common credential patterns and private runtime references.
- Added a hash-based browser script policy, blocked outbound app connections, and disabled referrers.
- Preserved the 1,600-resource catalog snapshot and the 1.0.1 document edition.

## 1.0.1 — 2026-10-08

- Renamed the project to AQuIRE, Awesome Quantum Information Research Explorer.
- Updated repository metadata, document editions, browser branding, and download filenames.
- Preserved the 8 October 2026 catalog snapshot, stable resource identifiers, and source references.
- Migrated existing browser bookmarks and theme preferences to AQuIRE storage keys.

## 1.0.0 — 2026-10-08

- Initial reference edition with 1,600 resources, 30 categories, 164 topics, and 792 fine subcategory entries.
- Self-contained explorer with combined filters, local bookmarks, theme selection, and filtered exports.
- Eight reading paths and complete Word, PDF, and Markdown reference editions.
- Reproducible HTML, CSV, BibTeX, and taxonomy builds; catalog validation and browser smoke tests.
- GitHub Actions checks and a manually triggered GitHub Pages deployment workflow.
