# AQuIRE: Awesome Quantum Information Research Explorer v1.0.3

The AQuIRE reference edition combines 1,600 bibliographic and official web resources with a detailed quantum computing taxonomy and a self-contained searchable explorer.

## Included

- 30 major categories, 164 topics, and 792 fine subcategory entries.
- 1,546 DOI-bearing Crossref records and 54 retrieved first-party resources.
- Eight reading paths and a complete 215-page PDF, editable DOCX, and Markdown reference edition.
- Combined filters, local bookmarks, light/dark themes, and filtered CSV, JSON, and BibTeX exports.
- Standard-library build tools, catalog validation, regression and browser smoke tests, and GitHub Pages configuration.

Snapshot: 8 October 2026. Source verification establishes retrieved bibliographic identity or successful first-party page retrieval. Subject classification is title screened or editorially curated, and the collection is not a full-text systematic review or a scientific-quality ranking.

OpenAI 6.1 sol was used to obtain and organize the initial resource collection and assist with project preparation. See the README acknowledgments and methodology for details.

Version 1.0.3 includes a reader-facing repository layout, public-file checks, and browser security policy controls. The catalog snapshot and the 1.0.1 reference document edition are preserved.
